# RJ Craft Studio Website

A free, mobile-friendly static website starter for RJ Craft Studio.

## Included
- Home / brand introduction
- Handmade Flowers
- Customizable Keychains
- Custom-order section
- About section
- Contact / WhatsApp placeholder
- Responsive mobile design

## Add later
1. Replace the product placeholder cards with real product photos.
2. Add prices.
3. Add your WhatsApp number.
4. Add Instagram link if wanted.
5. Optionally add a custom domain.

## Free hosting
This is a static website, so it can be hosted free on GitHub Pages or Cloudflare Pages.
